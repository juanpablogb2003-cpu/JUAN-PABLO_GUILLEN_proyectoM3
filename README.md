# JUAN-PABLO_GUILLEN_proyectoM3
Descripción

Este programa simula una Máquina de Galton con 3,000 canicas y 12 niveles. En cada nivel, las canicas tienen un 50% de probabilidad de moverse hacia la izquierda o hacia la derecha.

Se utilizaron las librerías random para generar los movimientos aleatorios y matplotlib para mostrar los resultados en un histograma.

El programa cuenta con dos funciones:

simular_galton(): realiza la simulación de las canicas.
graficar_histograma(): muestra los resultados en un histograma.
